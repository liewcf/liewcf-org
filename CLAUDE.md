# CLAUDE.md

This file provides guidance to Claude Code when working in this repository.

## Project

`liewcf.org` is currently a static profile site with Home and About pages generated by Astro from plain semantic HTML, CSS, and vanilla browser JavaScript.

Astro provides build and preview tooling only. The site has no server runtime, Tailwind, client-side UI framework, CMS, blog, completed projects/updates portfolio, contact form, or API backend.

## Commands

- Install dependencies: `npm install`
- Start local preview: `npm run dev`
- Run smoke checks: `npm run check`
- Run Playwright directly: `npm run test:e2e`

## Architecture

- `src/pages/index.astro` owns all homepage content, structured data, outbound links, and vanilla browser behavior.
- `src/pages/about.astro` owns the expanded factual About content.
- `src/layouts/SiteLayout.astro` owns shared metadata defaults, Home/About navigation, skip-link/main structure, and footer.
- `src/pages/404.astro` owns the branded noindex 404 page.
- `public/` contains stable CSS, assets, crawler/security/agent files, redirects, and headers.
- `dist/` is generated static production output and is not edited directly.
- `tests/e2e/navigation.spec.ts` contains Playwright smoke checks.

There is no framework runtime, content collection system yet, Cloudflare Pages Function, or runtime environment-variable requirement.

## Code Style

- Prefer semantic HTML and plain CSS.
- Keep the page concise and profile-focused.
- Keep changes small and easy to inspect.
- Do not add a blog, CMS behavior, server rendering, API functions, contact form, Turnstile, Resend, Tailwind, or a client-side UI framework unless an accepted ticket requires it.

## Contact And Links

- Contact is outbound-link only.
- Email uses `mailto:`.
- External profile links should have clear accessible names and safe `rel` attributes where appropriate.

## Validation

- Run `npm run check` after page, asset, or link changes when feasible.
- For visual changes, preview with `npm run dev` and inspect desktop and mobile widths.

## Deployment

Cloudflare Pages should publish Astro's generated static output.

Recommended settings:

- Build command: `npm run build`
- Output directory: `dist`
- Runtime environment variables: none

Run `npm run check` locally or in CI before deploying.
