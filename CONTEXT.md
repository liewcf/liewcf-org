# LiewCF.org

This context defines the public content concepts used by the personal profile and project-publishing site.

## Language

**Project**:
An original public GitHub repository selected to represent Liew CheonFong's work, with its own detail page and a timeline of its Updates. Private repositories, unmodified forks, archives, mirrors, and throwaway experiments are excluded unless deliberately promoted.

**Update**:
A dated publication about progress or change that belongs to exactly one Project.
_Avoid_: Blog Post, Article
