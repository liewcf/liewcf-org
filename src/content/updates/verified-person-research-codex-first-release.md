The Codex-first release replaced one exhaustive workflow with explicit Quick, Standard, and Deep modes. It made Identity Resolution a prerequisite, applied Claim Confidence labels across reports, kept Quick and Standard work in the current agent, and required separate permission before Deep Research could use parallel lanes or subagents.

The release verification mapped 227 requirements to implementation or test evidence, with every row passing. Repository and installed-package validators passed, installed-package parity passed, and the recorded end-to-end run passed 49 evaluation cases, 200 assertions, and 30 trigger cases split evenly between expected activations and non-activations.

The evidence is intentionally bounded. Live-web discovery quality, real access blocks, other agent hosts, publication, deployment, contact actions, real private data, and production use were not verified by that release record.
