Watch Later Manager for YouTube™ 0.1.7 is available in the Chrome Web Store. Watched-first sorting now recognises YouTube’s watched badge, and videos whose links load late become selectable.

The toolbar keeps the result of a batch removal visible when the sort order resets. If a removal fails, the video stays selected so you can try again.

[Get Watch Later Manager for YouTube™ in the Chrome Web Store](https://chromewebstore.google.com/detail/jleceiefdnhnjifpebbnlgjbmhijnmpn)
