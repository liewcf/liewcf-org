Image Zoom 0.1.5 is available in the Chrome Web Store. On sites where the zoom overlay stopped responding, you can scroll to zoom, drag to pan, and press Escape to close it again.

Links layered over photos stay clickable. The overlay also preserves the crop used by responsive images and can open image URLs that contain commas.

[Get Image Zoom in the Chrome Web Store](https://chromewebstore.google.com/detail/lkegbkodpcgmeaphnkmfcbdmdbnnaini) · [See the 0.1.5 changes on GitHub](https://github.com/liewcf/imagezoom/commit/7e7da46c42cbebd7f5803d9ad42b37bb87dd1265)
