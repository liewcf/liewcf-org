## Picking up where you left off

Start with `docs/TASKS.md` to see what’s still open. If you need to know why an earlier choice was made, look in `docs/DECISIONS.md`. Both files live in the project folder, where you and your coding assistant can read them.

At the end of a session, record what changed, which checks passed, and the next step. Those notes give the next session a place to start, even if you switch assistants.
