## How it works

Ask Codex to review uncommitted changes, a commit, or a branch comparison. Hydrogen Review sends the selected diff and relevant files to Gemini 4 Hydrogen High through Antigravity CLI. Codex checks the findings against your code and points you to the affected lines. The review is read-only.

## Getting started

The launcher runs on macOS and needs Codex and a signed-in Antigravity CLI with access to Gemini 4 Hydrogen High. Google receives the review prompt and any code or context you approve for sharing. [Installation and usage instructions](https://github.com/liewcf/hydrogen-review-skill#install)
