## What it does

EnjinMel SMTP intercepts WordPress `wp_mail()` calls and sends them through the Enginemailer REST API. Existing WordPress code can keep using the familiar mail function while the plugin handles the external delivery service.

## Useful administration

The plugin includes settings and test-email screens, email logging, filtering, and CSV export in WordPress administration. API credentials are encrypted before storage.
